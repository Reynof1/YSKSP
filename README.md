## 📖 Tentang Proyek

Yayasan Sosial Kristen Salib Putih (YSKSP) adalah organisasi nirlaba yang telah melayani masyarakat Indonesia selama lebih dari satu abad. Website ini menampilkan:

- **Profil & Sejarah** yayasan
- **Program Pelayanan**: Sosial, Pendidikan, Kesehatan, dan Kemandirian
- **Informasi Kontak** dan Lokasi
- **Navigasi User-Friendly** dengan desain modern

---

## ✨ Fitur Utama

✅ **Responsif** - Optimal di desktop, tablet, dan mobile  
✅ **Fast Loading** - Dioptimalkan dengan Vite  
✅ **Modern UI** - Tailwind CSS + Motion animations  
✅ **SEO Friendly** - Metadata dan structured data  
✅ **Multi-halaman** - Navigasi antar section yang smooth  
✅ **Google Gemini AI** - Integrasi untuk fitur interaktif
